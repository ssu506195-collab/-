# 鏡界裂痕｜威爾第二階段模式辨識與走位訓練器

這是以《楓之谷 M》威爾第二階段小遊戲的「觀察第一戳特徵、辨認組合、記住三次戳擊動線」為核心的原創單頁網頁。`index.html` 內含 HTML、CSS、JavaScript；原創 SVG 及可替換角色素材放在 `assets/`。

## 玩法

1. 每輪開始時呈現第一戳的上下排蜘蛛腳排列，以及地板有／無裂痕的視覺線索。
2. 開局先呈現第一戳線索約 2 秒，玩家必須在第一戳發生前提交模式辨識答案（A–G 或 H）；第一戳開始後答案鎖定。
3. 每次戳擊之間預設相隔 3 秒；可切換為 4 秒熟悉模式或 2 秒快速模式。
4. **無裂痕：** 要避開蜘蛛腳落點。**有裂痕：** 要站到蜘蛛腳落點接腳。
5. 每輪固定三次戳擊，結束後會顯示模式答案、建議路線、實際站位、受傷結果與模式辨識是否正確。記憶考驗模式不會在後兩戳前預告腳位；教學模式才會顯示後續預告與建議路線。

## 題庫設定

- **混沌模式：** 七種固定配置 A–G。
- **困難模式：** 三種配置 A、B、H（沿用共通的 A、B，再加困難專用裂痕配置 H）。
- **隨機抽取：** 在目前題庫內洗牌，盡量避免題目連續重複。
- **依序輪替：** 按題庫排列依次練習。

題型資料保留了上下腳位可能稍微偏離格線的特性。碰撞範圍及顯示時序是本訓練器的重建設定，仍應依你實際遊玩的版本校正。

## 操作

- `←` / `→` 或 `A` / `D`：左右移動。
- 開局辨識倒數期間，使用右側模式按鈕或數字鍵選擇模式；第一戳開始時答案鎖定。
- `P` 或 `Esc`：暫停／恢復。
- `R`：重新開始挑戰。
- 點擊地板也可以將角色移動到該位置；手機版有左右觸控按鈕。

## 自訂角色素材

把有權使用的透明 PNG 放到 `assets/character/`：

- `player-idle.png`：待機圖。
- `run-1.png` 至 `run-6.png`：跑步動畫，每個影格一張圖。
- `player-hurt.png`：受傷圖（選用）。

缺少角色圖時會顯示內建原創占位角色，不影響遊戲操作。更多細節請看 `assets/character/README.md`。

## GitHub Pages 部署

1. 建立一個 GitHub Repository。
2. 將 `index.html`、`README.md` 和整個 `assets/` 資料夾上傳至 Repository 根目錄。
3. 開啟 **Settings → Pages**，選擇 `main` 分支與 `/(root)` 目錄進行部署。
4. 發布後開啟 GitHub Pages 網址，測試角色素材、蜘蛛腳動畫、模式辨識、走位、暫停和重玩功能。
